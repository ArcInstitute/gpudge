# gpudge v0.2.0 — 2026-06-01

Explicit, opt-in per-gene expression filtering for `de()`, plus performance and hardening work. **This release contains a breaking change.**

## ⚠️ Breaking change — `min_feature_filter` removed

`de()` filtering is now **opt-in**. The single ambiguous `min_feature_filter` is **removed** (passing it now raises `ValueError` with migration guidance) and replaced by four explicit, unit-named, AND-combinable per-gene filters plus a boolean-mask escape hatch — all default `None` (no filtering):

| New parameter | Operates on | Notes |
| --- | --- | --- |
| `filter_gene_min_mean_value` | `adata.X` **as supplied** | unit-agnostic; never warns |
| `filter_gene_min_total_value` | `adata.X` as supplied (per-group sum) | unit-agnostic; never warns |
| `filter_gene_min_cpm_cell` | mean of per-cell CPM | assumes raw counts; warns on non-count X |
| `filter_gene_min_cpm_bulk` | pooled bulk CPM (Σcounts/Σlibsize·1e6) | assumes raw counts; warns on non-count X |
| `keep_genes` | per-gene boolean mask (var-aligned) | escape hatch for non-count X |

Filters AND-combine; within each it's target-OR-reference; a **negative** threshold = keep-all; `0.0` keeps only strictly-positive genes. BH-FDR is computed over the survivors per target group.

### Migrating off `min_feature_filter=v`

| Old call | New call |
| --- | --- |
| `min_feature_filter=v`, `cpm_normalize=False` | `filter_gene_min_mean_value=v` |
| `min_feature_filter=v`, `cpm_normalize=True` | `filter_gene_min_cpm_cell=v` |
| `min_feature_filter=0.0` ("minimal") | the matching unit at `0.0`, or omit for no filter |

(Closes #26.)

## Added

- `de(oom_recovery=True)` (default): on a CUDA OOM while processing a gene-chunk, `gpu_gene_chunk_size` is halved (floor 64) and retried, logging each downshift — both reference modes. Pass `oom_recovery=False` for strict mode. (#22, #28)

## Changed

- `auto` `gpu_gene_chunk_size` budget fraction raised 0.18 → 0.20 (lands ~4096 on A100-40GB/cell line 2, the measured throughput knee). Result-invariant `de()` speedup: ~7% on A100-40GB, ~3% on H100-80GB; neutral on larger GPUs. (#22, #28)
- `de()` now validates `mean_calc`, `epsilon`, and `output_columns` at entry, before any GPU work, raising immediately on bad values.

## Performance (result-invariant)

- Vectorized the Mann–Whitney tie-correction term and trimmed per-chunk GPU transients in both paths. (#30)
- A `filter_gene_min_cpm_bulk`-only run no longer allocates the per-cell `row_scales` or per-group row-index GPU tensors it never uses. (#32, #33)

## Packaging / install

- **`shardad` is now optional** — the `[streaming]` extra, for `de(shard_archive=…)`. The core `de()` takes an in-memory `AnnData` and never imports it, so a default install no longer pulls the private git dependency.
- README now documents **pip**, **uv**, and **conda/mamba** installs; added `environment.yml`. Not yet on PyPI — install from the `v0.2.0` git tag (requires ArcInstitute SSH access).

## Internal

- GCP single-tenant A100 benchmark harness for contention-free wall-time sweeps. (#19, #20)

## Known issues (carried from v0.1.0)

- `reference="all_others"` (lowercase string) still works with a `DeprecationWarning`; the removal version is deferred. Prefer the `ALL_OTHERS` constant.
- shardad **v2** archive loading is ~16× slower than v1 at cell line 2 scale; stay on v1 archives for cell line 2-scale inputs until shardad's on-GPU read path lands.
